# העיצוב החדש של Oz Digital

החבילה כוללת את העיצוב המאושר והמעודכן מ־7 בספטמבר 2026, בעברית ובאנגלית, עם כל קובצי הקוד, הפונטים, הלוגואים והרישיונות.

## מה יש בחבילה?

- `site/index.html` — פתיחת העיצוב לצפייה בדפדפן.
- `site/app.js` — התוכן בשתי השפות וההתנהגות האינטראקטיבית.
- `site/style.css` — עיצוב העמוד והתאמה למסכים שונים.
- `site/accessibility.css` — אפשרויות נגישות והתאמות תצוגה.
- `site/accessibility.html` ו־`site/accessibility.js` — הצהרת נגישות בשתי השפות.
- `site/assets/` — כל הלוגואים, הפונט המקומי והרישיונות.
- `IMPLEMENTATION_PROMPT.md` — פרומפט מלא באנגלית להטמעה בפרויקט הקיים באמצעות Codex או Claude Code.
- `SOURCE_NOTES.md` — מידע על מקור הנכסים ועל ההתנהגות של גרסת העיצוב.

## איך משתמשים בחבילה?

1. חלצו את קובץ ה־ZIP. לצפייה מיידית בעיצוב, פתחו את `site/index.html` בדפדפן.
2. לצורך ההטמעה, מקמו את התיקייה `oz-digital-flow-design` בתוך תיקיית `design` בפרויקט הקיים:

```text
D:\code\oz-digital-solutions\design\oz-digital-flow-design
```

3. פתחו את Codex או Claude Code בתוך פרויקט `oz-digital-solutions`.
4. העתיקו את מלוא התוכן של `IMPLEMENTATION_PROMPT.md` לשיחה איתו. הפרומפט מפנה לקבצים בחבילה ומפרט מה להטמיע ומה לשמר.

## מה חשוב בשילוב באתר הקיים?

זו חבילת עיצוב אינטראקטיבית ב־HTML, CSS ו־JavaScript. האתר הקיים בנוי ב־Next.js, ולכן יש להעביר את העיצוב לרכיבים ולמבנה הקיימים בפרויקט. אין צורך להחליף את כל הפרויקט בקבצי החבילה.

הפרומפט כולל הוראות לשמר את עמודי השירותים, המדריכים, תוכן המאמרים, קישורי השותפים, SEO, מדידה וטופס יצירת הקשר הקיים. העיצוב המאושר מסיר לחלוטין את הצגת הפרויקטים מהעמוד ומקישורי הניווט.

בגרסת העיצוב, הטופס פותח טיוטת מייל. בהטמעה יש לחבר את המראה החדש למנגנון השליחה האמיתי שכבר קיים באתר, עם מצבי שגיאה והצלחה.

החבילה כוללת חזרה למעלה, עצירת תנועה, ניגודיות מוגברת והצהרת נגישות. לא בוצעה בדיקת עמידה מלאה בתקן נגישות; בהטמעה יש לשמור על הצהרה מדויקת ולעדכן אותה לפי מה שנבדק בפועל.

פעולות Git שמשנות את הפרויקט, כולל staging, commit ו־push, נשארות לביצוע ידני שלך. הפרומפט אינו מאשר פרסום לאתר החי.
